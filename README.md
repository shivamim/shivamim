## 🧠 About Me

- 🏗️ I build production grade AI platforms end to end. Schema design, async backend, real time frontend, deployment pipeline, all of it, solo.
- 🏥 Currently building **Ojas HealthTech**, a multi tenant SaaS platform that helps Indian hospitals monitor patients for 14 days post discharge over WhatsApp, with AI driven risk scoring and one click NABH compliance reporting.
- 🤖 My systems lean on **LangGraph orchestration**, **hybrid RAG** (dense retrieval plus BM25 plus Reciprocal Rank Fusion plus reranking), and **AutoML with SHAP explainability**. Not single prompt wrappers dressed up as products.
- 📊 My roots are in **SQL, Power BI, and statistical analysis**. That's why my AI systems care about grounding, evaluation metrics, and measurable business impact, not just a slick chat window.
- 🇮🇳 Focused on real problems for the Indian market: WhatsApp native workflows, Hindi and Hinglish distress detection, and regulatory compliance like NABH and DPDPA.
- 🌱 Currently exploring agentic security tooling (hybrid RAG over MITRE ATT&CK and CVE data) and hardening healthtech infrastructure for a live hospital pilot.

### 🏥 Ojas HealthTech V2
**Multi tenant, NABH compliant post discharge patient recovery platform for Indian hospitals.**

<a href="https://ojas-v2.vercel.app"><img src="https://img.shields.io/badge/LIVE%20APP-Visit%20Now-0d9488?style=for-the-badge" alt="live"/></a>
<a href="https://github.com/shivamim/Ojas-V2"><img src="https://img.shields.io/badge/REPO-View%20Code-14b8a6?style=for-the-badge&logo=github&logoColor=white" alt="repo"/></a>
<img src="https://img.shields.io/badge/STATUS-Active%20Development-22c55e?style=for-the-badge" alt="status"/>
<img src="https://img.shields.io/badge/LICENSE-BUSL%201.1-f59e0b?style=for-the-badge" alt="license"/>

- 14 day automated WhatsApp check in protocol with AI driven risk scoring across pain, fever, swelling, bleeding, and breathing difficulty, plus bilingual English and Hindi/Hinglish distress detection.
- True multi tenant architecture. Every request is scoped through a `require_tenant()` guard, backed by a Super Admin control plane and token based hospital invite onboarding, no manual SQL required.
- One click NABH compliance reporting (COP 7.3, 7.3.1, 7.4, 5.6) with SHA-256 hashed PDFs for tamper evidence.
- Field level encryption on patient PII (AES via Fernet, PBKDF2-HMAC-SHA256 key derivation), JWT auth with rotating refresh tokens, full audit logging, and rate limiting on every privileged action.
- Hardened for production: CSP, HSTS, gzip and brotli compression, non-root Docker containers, and a keep-alive GitHub Action that defeats free-tier cold starts.

`FastAPI` `PostgreSQL` `SQLAlchemy 2.0` `React 18` `TypeScript` `shadcn/ui` `Docker` `Render` `Vercel` `Supabase`

### 🤖 FiveMinds
**Multi agent AI analytics platform. Upload a CSV, ask a question, get boardroom ready insights in under 30 seconds.**

<a href="https://fiveminds-9ru0.onrender.com"><img src="https://img.shields.io/badge/LIVE%20APP-Visit%20Now-6366f1?style=for-the-badge" alt="live"/></a>
<a href="https://github.com/shivamim/FiveMinds"><img src="https://img.shields.io/badge/REPO-View%20Code-8b5cf6?style=for-the-badge&logo=github&logoColor=white" alt="repo"/></a>
<img src="https://img.shields.io/badge/LICENSE-MIT-22c55e?style=for-the-badge" alt="license"/>

- 5 specialized LLM agents (Data Engineer, Statistician, ML Engineer, Strategist, Designer) collaborating in real time over a shared pipeline, powered by Groq running Llama 3 8B and 70B.
- A real statistical profiling engine (Pearson correlations, IQR outlier detection, histograms) feeds the Strategist agent instead of relying on mock outputs.
- AutoML across 5 models (Random Forest, XGBoost, LightGBM, Logistic Regression, SVM) with SHAP explainability. Best model hit a 73% F1 score.
- Real time WebSocket progress tracking under 100ms push latency, with one click export to PDF, Excel, PPT, and HTML.
- Zero downtime schema auto migration on boot, deployed across Render, Railway, and Supabase.

`React 18` `Vite` `TypeScript` `FastAPI` `SQLAlchemy 2.0` `Groq API` `PostgreSQL` `WebSockets`

### 🛡️ SentinelIQ
**Agentic hybrid RAG platform for cybersecurity investigation.**

<a href="https://github.com/shivamim/SentinelIQ"><img src="https://img.shields.io/badge/REPO-View%20Code-0f172a?style=for-the-badge&logo=github&logoColor=white" alt="repo"/></a>
<img src="https://img.shields.io/badge/ARCHITECTURE-Hybrid%20RAG-a855f7?style=for-the-badge" alt="architecture"/>

- Hybrid retrieval combining dense vector search (pgvector, Voyage AI `voyage-3` embeddings) with PostgreSQL BM25 lexical search, fused via Reciprocal Rank Fusion and reranked with Cohere `rerank-v3-enterprise`.
- LangGraph orchestrated, 11 node pipeline handling alert triage, incident correlation, IOC analysis, and MITRE ATT&CK mapping.
- Neo4j attack graphs for asset correlation and blast radius analysis, with SSE streamed attack replay in a Next.js frontend.
- Grounding verification on every answer (fully grounded, partially grounded, ungrounded, or evidence insufficient), fabricated citation detection, and confidence based abstention instead of guessing.
- A full RAG evaluation suite (Recall@K, MRR, NDCG@K) that benchmarks BM25 only vs vector only vs hybrid vs hybrid plus rerank side by side.

`FastAPI` `Next.js 14` `LangGraph` `Neo4j` `pgvector` `Groq` `Voyage AI` `Cohere` `Redis`

  schedule:

  workflow_dispatch:
  push:

      - main

jobs:
  generate:

    steps:
      - uses: Platane/snk@v3
