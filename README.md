### RAGBT
**"dbt for RAG" / Declarative, incremental, tested embedding pipelines. Published on PyPI.**

<a href="https://pypi.org/project/ragbt/"><img src="https://img.shields.io/badge/PyPI-v0.1.0-3775A9?style=for-the-badge&logo=pypi&logoColor=white" alt="pypi"/></a>
<a href="https://github.com/shivamim/ragbt"><img src="https://img.shields.io/badge/REPO-View_Code-181717?style=for-the-badge&logo=github&logoColor=white" alt="repo"/></a>
<img src="https://img.shields.io/badge/LICENSE-Apache_2.0-22c55e?style=for-the-badge" alt="license"/>
<img src="https://img.shields.io/badge/PYTHON-3.10+-3776AB?style=for-the-badge&logo=python&logoColor=white" alt="python"/>

```bash
pip install ragbt
ragbt init my_project
ragbt run      # incremental, content-hash based
ragbt test     # retrieval assertions that fail CI
ragbt docs generate  # lineage graph + manifest
```

- Content-hash incremental runs: only changed documents are re-chunked and re-embedded. Subsequent runs are near-instant.
- Retrieval tests as first-class citizens: assert that queries return the right docs before shipping to production.
- Full lineage from source to chunks to vectors via `manifest.json`, reviewable in PRs.
- Multi-target support: isolated dev/prod environments with `--target` flag.
- Pluggable architecture: swappable chunkers (recursive, markdown), embedders (Voyage AI, OpenAI), and vector stores (pgvector with HNSW).
- CLI-native: `ragbt init`, `ragbt run`, `ragbt test`, `ragbt ls`, `ragbt docs generate`.

`Python` `Pydantic` `pgvector` `Voyage AI` `OpenAI` `Click` `PyPI`

### SENTINELIQ
**Agentic hybrid RAG platform for cybersecurity investigation. 11-node LangGraph pipeline with grounding verification and abstention.**

<a href="https://github.com/shivamim/SentinelIQ"><img src="https://img.shields.io/badge/REPO-View_Code-0f172a?style=for-the-badge&logo=github&logoColor=white" alt="repo"/></a>
<img src="https://img.shields.io/badge/ARCHITECTURE-Hybrid_RAG-a855f7?style=for-the-badge" alt="architecture"/>
<img src="https://img.shields.io/badge/STATUS-Active_Development-22c55e?style=for-the-badge" alt="status"/>

- **Hybrid retrieval at depth:** dense vector search (pgvector + Voyage AI `voyage-3` embeddings) fused with PostgreSQL BM25 lexical search via Reciprocal Rank Fusion (k=60), then reranked with Cohere `rerank-v3-enterprise`.
- **LangGraph orchestration:** 11-node StateGraph handling alert triage, incident correlation, IOC analysis, and MITRE ATT&CK mapping. Redis-backed conversation memory with query rewriting.
- **Grounding verification on every answer:** classified as fully grounded, partially grounded, ungrounded, or evidence insufficient. Fabricated citation detection with strict abstention instead of hallucination.
- **Neo4j attack graphs:** real Cypher queries for asset correlation and blast radius analysis, streamed via SSE to a Next.js 14 frontend.
- **RAG evaluation suite:** Recall@K, MRR, NDCG@K benchmarking BM25-only vs vector-only vs hybrid vs hybrid+rerank side by side with gold-labeled datasets.
- **Production deployment:** FastAPI backend on Railway, Next.js frontend on Vercel, Supabase PostgreSQL, Upstash Redis, Neo4j Aura, Langfuse observability.

`FastAPI` `Next.js 14` `LangGraph` `Neo4j` `pgvector` `Groq` `Voyage AI` `Cohere` `Redis` `Langfuse`
